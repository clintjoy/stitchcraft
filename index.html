Use on Android & iOS + Transfer Shop Data

1. Transfer / Sync Shop Data Across Phones

Export your customers, saved measurements, orders, and karigar wages as a backup file to load onto any other Android or iPhone.

Android (APK / Home App)
  1. Download the stitchcraft_mobile_build.zip package from chat.
  2. Open index.html in Chrome on Android and tap Menu (⋮) → Add to Home Screen / Install App.
  3. Or build a native .apk via Capacitor (npx cap open android) or PWABuilder.com.
iPhone & iPad (iOS)
  1. Host the folder free on GitHub Pages / Netlify or open in Safari.
  2. Tap the Share icon at the bottom of Safari.
  3. Tap Add to Home Screen. It launches full-screen like a native iOS app with offline storage.
